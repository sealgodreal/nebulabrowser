PRIVACY POLICY (updated 5/6/26):

# Information Automatically Received
When you use Nebula, the server automatically receives certain data as part of normal web communication, including:
IP address (from your network connection)
User-Agent (browser and device information)
Requested URLs and request headers
Cookies (if the visited site uses them)
This information is required for the service to function as a web proxy.

# How Information Is Used
IP address is used to send a request to the proxy server.
User-Agent data is used only to properly forward web requests.
Cookies are used temporarily to maintain compatibility with proxied websites.
Request data is processed in memory only while handling the request.

# Data Storage
Nebula does not maintain a user database.
Nebula does not persistently store personal data.
Temporary caching may occur for performance, but is not user-specific.

# Data Sharing
We do not sell, share, or distribute any user data.
However, because Nebula functions as a proxy, requests are forwarded to third-party websites, and those websites may collect data according to their own privacy policies.

# Important Notice
Nebula is intended for activities such as gaming and simple browsing. Users are responsible for how they use the service.
Misuse of this service is not the responsibility of the developer.
